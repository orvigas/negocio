# Accesibilidad

La accesibilidad es obligatoria.

Asegúrate de incluir:

- HTML semántico
- navegación mediante teclado
- estados de foco visibles
- etiquetas apropiadas
- texto significativo en botones
- formularios accesibles
- contraste suficiente
- jerarquía correcta de encabezados
- ARIA apropiado solo cuando sea necesario
- imágenes con texto `alt` significativo cuando corresponda

Nunca utilices ARIA para compensar un HTML semánticamente incorrecto cuando un elemento HTML nativo pueda resolver el problema.
