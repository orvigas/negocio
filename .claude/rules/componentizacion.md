# Componentización

Construye componentes de UI reutilizables utilizando HTML, BEM, Tailwind y JavaScript Vanilla.

Antes de crear un componente nuevo:

1. Busca una implementación existente.
2. Comprueba CodeGraph cuando esté disponible.
3. Reutiliza los patrones existentes cuando sea apropiado.
4. Evita duplicaciones innecesarias.

No crees abstracciones simplemente por el hecho de abstraer.
