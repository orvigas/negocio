# Definición de hecho

Antes de finalizar una tarea:

- Comprende el código existente.
- Utiliza CodeGraph cuando esté disponible.
- Revisa las reglas del proyecto.
- Implementa el cambio mínimo necesario.
- Mantén las convenciones existentes.
- Valida entradas externas.
- Considera seguridad.
- Agrega o actualiza pruebas.
- Ejecuta lint y tests relevantes.
- Revisa errores y regresiones.
- Verifica que no existan cambios innecesarios.
- Actualiza documentación cuando corresponda.

Una tarea no está terminada simplemente porque el código compile.

Debe quedar funcional, probado y coherente con el proyecto.
