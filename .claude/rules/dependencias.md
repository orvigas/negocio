# Dependencias

Antes de agregar una dependencia:

- Comprueba si el proyecto ya tiene una solución existente.
- Evalúa si Node.js o el stack actual pueden resolverlo.
- Evalúa mantenimiento y compatibilidad.
- Comprueba impacto en seguridad.
- Agrega la dependencia únicamente si aporta valor real.

No agregues librerías por conveniencia cuando una solución nativa sea suficiente.

No introduzcas un segundo framework para resolver un problema que Koa.js ya puede manejar mediante middleware.
