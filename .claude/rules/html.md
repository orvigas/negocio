# HTML5

Utiliza HTML5 semántico.

Prefiere elementos como:

- `header`
- `nav`
- `main`
- `section`
- `article`
- `aside`
- `footer`
- `button`
- `form`
- `label`

Evita elementos `<div>` innecesarios cuando exista un elemento semántico apropiado.

El HTML debe ser:

- válido
- semántico
- accesible
- estructuralmente claro
- compatible con navegadores modernos
